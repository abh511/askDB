    How it works

    1. Find tables the question needs (vector search over table descriptions)
    2. Write SQL with an LLM, guided by 3 similar solved examples
    3. Safety guard checks it is a single read-only SELECT on known tables
    4. Run as a read-only database user (5 s timeout, max 500 rows); if it errors, the LLM fixes it (up to 2 retries)
    5. Answer in one sentence, with a table and a chart

    Data: ~100K Brazilian e-commerce orders, Sep 2016 – Oct 2018, money in R$.
